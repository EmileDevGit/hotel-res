* HotelRes

** Description

HotelRes est une application intuitive et efficace, permettant à vos clients de réserver leur séjour sans tracas.
L'objectif est simple, une solution mobile assurant le suivi des réservation pour l'entreprise d'hotellerie et la clientèle.


**** Fonctionnalitées

- Sélection de chambres libres
  - L'information est mise à jour en temps réel
  - Réservation journalière ou par période 


- Confirmation de réservation.
  - Enregistrement local au format PDF
  - Sauvegarde sur le serveur distant
  - Historique des réservations


- Synchronisation du calendrier.
  - Intégration au préférences client
  - Organisation efficace


- Authentification.
  - Sécuritaire
  - Conservation de l'historique de réservation
  - Confidentialité des réservations
  - Potentiel d'offres avantageuses ciblées


** Installation
  1. Générer un token ici: http://idefix.dti.crosemont.quebec:10170/auth/login
  2. Insérer le token dans les préférences de l’application
  3. Compiler et lancer l’application depuis Android Studio
